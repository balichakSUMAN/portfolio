# Deployment on InfinityFree (Static Hosting)

InfinityFree only supports static files (HTML, CSS, JS). You cannot run Node.js or Vite servers. To deploy your React portfolio:

1. Build your project for production:
   ```
   npm run build
   ```
   This creates a `dist` folder with static files.

2. Upload everything inside the `dist` folder to your InfinityFree `htdocs` or `public_html` directory using the file manager or FTP.

3. (Optional but recommended) Make sure the file `public/_redirects` exists with this content:
   ```
   /*    /index.html   200
   ```
   This ensures all routes work for a single-page app.

4. All asset paths are relative, so images and CSS will work after upload.

5. Do not upload your source code or `node_modules`—only the contents of `dist`.

---

If you need to update your site, rebuild and re-upload the new `dist` contents.
